# Sistemas web, Python e integrações

A Smart Control Brasil desenvolve sistemas sob medida, integrações e soluções digitais para operação.

## Escopo aprovado
- Desenvolvimento em Python.
- Sistemas web e websites.
- Lojas virtuais.
- Integrações entre sistemas.
- Automações de processos.
- IoT, telemetria e aquisição de dados.
- Firmwares e hardware sob medida quando o projeto exigir.
- Soluções com IA aplicadas a dados e operação, sem promessa mágica.

## Como começa
Diagnóstico do cenário, definição de arquitetura, desenvolvimento/testes, start-up e sustentação técnica.

## Limite
Preço, prazo e escopo dependem do levantamento. Não inventar valores nem cronogramas.
